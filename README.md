# 🐱 Virtual Desktop Cats Simulator (Pygame)

Un simulateur de compagnons virtuels de bureau inspiré des extensions de type *VS Code Pets*, développé en **Python** avec **Pygame**.

---

## 📸 Fonctionnalités

- 🐾 **Compagnons animés et nommés :** Chaque chat possède son propre prénom, sa couleur, et se balade librement sur ton bureau virtuel.
- 💤 **Comportements dynamiques :** Les chats alternent entre marche, sieste (avec de mignons "z Z z") et exploration.
- 🧶 **Interaction au clic :** Clique n'importe où sur l'écran pour déposer un jouet/laser : tous les chats vont courir ensemble vers l'objectif !
- ➕ **Adoption illimitée :** Appuie sur la touche `C` à tout moment pour adopter instantanément un nouveau chat avec un prénom aléatoire.

---
